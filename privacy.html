Kebijakan Privasi – GoSmart Tools

Terakhir diperbarui: 22 Februari 2026

1. Pendahuluan

Selamat datang di GoSmart Tools. Kebijakan Privasi ini menjelaskan bagaimana GoSmart Tools ("Kami", "Platform", atau "Layanan") mengumpulkan, menggunakan, menyimpan, melindungi, dan mengungkapkan informasi pengguna dalam penggunaan layanan digital kami. Dengan mengakses atau menggunakan GoSmart Tools, Anda menyetujui praktik yang dijelaskan dalam Kebijakan Privasi ini.

2. Kepatuhan Hukum

GoSmart Tools berkomitmen untuk mematuhi peraturan perlindungan data yang berlaku, termasuk namun tidak terbatas pada:

  • Undang-Undang No. 27 Tahun 2022 tentang Perlindungan Data Pribadi (Indonesia)
  • Ketentuan peraturan turunan yang berlaku
  • Prinsip perlindungan data internasional yang relevan

Kami hanya memproses data secara sah, adil, dan transparan.

3. Informasi yang Kami Kumpulkan

3.1 Informasi yang Diberikan Secara Langsung

  • Nama lengkap
  • Email
  • Nomor telepon
  • Informasi akun
  • Informasi pembayaran (jika berlaku)
  • API key atau kredensial yang secara sukarela dimasukkan oleh pengguna untuk keperluan integrasi

3.2 Informasi Otomatis

  • Alamat IP
  • Tipe perangkat
  • Browser dan sistem operasi
  • Log aktivitas
  • Data penggunaan fitur
  • Cookie dan teknologi pelacakan serupa

3.3 Informasi dari Pihak Ketiga

Jika Anda menggunakan layanan pihak ketiga (misalnya payment gateway, layanan API, atau autentikasi), kami dapat menerima data terbatas sesuai izin yang Anda berikan.

4. Tujuan Penggunaan Data

  • Mengelola dan mengoperasikan layanan
  • Memproses pendaftaran dan autentikasi akun
  • Memberikan akses fitur full pengguna
  • Memproses transaksi dan pembayaran
  • Meningkatkan performa dan keamanan sistem
  • Mengirim notifikasi terkait layanan
  • Melakukan analitik internal
  • Mencegah penyalahgunaan dan aktivitas ilegal

Kami tidak menjual data pribadi pengguna.

5. Penggunaan API Key dan Data Sensitif

  • Data API Key digunakan hanya untuk fungsi teknis sesuai permintaan pengguna
  • Kami tidak membagikan API Key kepada pihak lain
  • Kami tidak menggunakan API Key untuk kepentingan selain yang diminta pengguna
  • Pengguna bertanggung jawab atas keamanan kredensial mereka sendiri

6. Pembagian Informasi

  • Kepada penyedia layanan resmi (misalnya payment gateway, server hosting, sistem notifikasi)
  • Jika diwajibkan oleh hukum atau perintah pengadilan
  • Untuk melindungi hak hukum dan keamanan sistem
  • Dalam proses merger atau akuisisi (dengan perlindungan data tetap berlaku)

7. Penyimpanan dan Keamanan Data

Kami menerapkan langkah teknis dan administratif untuk melindungi data, termasuk:

  • Enkripsi saat transmisi (HTTPS)
  • Pembatasan akses internal
  • Sistem autentikasi aman
  • Monitoring aktivitas mencurigakan

Meskipun demikian, tidak ada sistem digital yang 100% aman. Pengguna memahami risiko inheren internet.

8. Hak Pengguna

Sesuai hukum yang berlaku, pengguna memiliki hak untuk:

  • Mengakses data pribadi
  • Memperbaiki data yang tidak akurat
  • Menghapus data tertentu
  • Membatasi pemrosesan data
  • Menarik persetujuan
  • Mengajukan keluhan kepada otoritas terkait

Permintaan dapat diajukan melalui kontak resmi yang tersedia di platform.

9. Cookie dan Teknologi Pelacakan

  • Autentikasi sesi
  • Preferensi pengguna
  • Analitik performa
  • Peningkatan pengalaman pengguna

Pengguna dapat mengatur preferensi cookie melalui pengaturan browser.

10. Penggunaan oleh Anak di Bawah Umur

Layanan ini tidak ditujukan untuk anak di bawah 18 tahun kecuali dengan pengawasan orang tua atau wali sah. Kami tidak secara sengaja mengumpulkan data anak tanpa persetujuan yang sah.

11. Retensi Data

Kami menyimpan data hanya selama diperlukan untuk tujuan operasional, kepatuhan hukum, penyelesaian sengketa, dan pencegahan penipuan. Setelah itu, data akan dihapus atau dianonimkan.

12. Tanggung Jawab Pengguna

  • Menjaga keamanan akun
  • Tidak menyalahgunakan layanan
  • Tidak menggunakan platform untuk aktivitas ilegal
  • Tidak mengunggah konten yang melanggar hukum

13. Pembaruan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu. Versi terbaru akan selalu tersedia di halaman resmi GoSmart Tools. Penggunaan berkelanjutan setelah pembaruan berarti Anda menyetujui kebijakan terbaru.
